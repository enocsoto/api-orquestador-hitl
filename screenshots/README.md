Las capturas del dashboard van acá, después de correr las 5 peticiones con la clave del modelo y Phoenix o LangSmith prendidos:

- `trazas.png`: una traza de una ejecución, con los nodos del grafo.
- `costo.png`: el costo por ejecución que calcula la plataforma con los tokens.
- `latencia-p95.png`: la latencia p95 de esa corrida.

Sin una corrida real contra el modelo, el dashboard no tiene costo ni p95. No se inventan las imágenes.
